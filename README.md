AIR//STUDIO

NOTE: THIS IS A PERSONAL PROJECT MADE FOR FUN, EXPERIMENTATION, AND DEMO PURPOSES. IT IS NOT A COMMERCIAL PRODUCT.

PROJECT OVERVIEW
This project is a hand-tracking music interface built in the browser. It lets a user use their webcam and hand movements to trigger instrument sounds in real time. The concept is inspired by live electronic performance and experimental music tools.

WHAT THE PROJECT OFFERS
- DRUM MODE FOR ELECTRONIC-STYLE PERCUSSION
- PIANO MODE WITH NOTE TRIGGERING
- XYLOPHONE MODE WITH BRIGHT MELODIC TONES
- CAMERA-BASED HAND TRACKING
- ADJUSTABLE SENSITIVITY AND VOLUME CONTROLS
- DIFFERENT LAYOUT OPTIONS FOR PLAYING COMFORT
- PRIVACY BLUR OPTION FOR FACE MASKING
- LIVE VISUAL FEEDBACK FOR MOTION AND HITS

TECHNOLOGY USED
- HTML FOR THE APP STRUCTURE
- CSS FOR STYLING AND LAYOUT
- JAVASCRIPT FOR APP LOGIC
- MEDIAPIPE HANDS FOR HAND DETECTION
- WEB AUDIO API FOR SYNTHESIS AND PLAYBACK
- CANVAS FOR LIVE VISUAL OVERLAYS AND MOTION RENDERING
- BROWSER CAMERA ACCESS FOR LIVE INTERACTION

PROJECT PURPOSE
This is a personal project made for experimentation, creative play, and prototype testing. It is not a commercial product and is not intended to be a full production application.
