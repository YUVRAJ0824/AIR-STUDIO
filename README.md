CURRENT BRANCH: EXP

PROJECT OVERVIEW
AIR//STUDIO IS A BROWSER-BASED HAND-TRACKING MUSIC EXPERIMENT THAT USES A WEBCAM TO DETECT HAND MOVEMENTS AND TRIGGER LIVE SOUNDS. IT IS BUILT AS A CREATIVE PROTOTYPE FOR PLAYING WITH MUSIC, MOTION INPUT, AND INTERACTIVE PERFORMANCE DESIGN.

FEATURES
- DRUM MODE FOR ELECTRONIC-STYLE PERCUSSION
- PIANO MODE WITH NOTE TRIGGERING
- XYLOPHONE MODE WITH BRIGHT MELODIC TONES
- CAMERA-BASED HAND TRACKING
- ADJUSTABLE SENSITIVITY AND MASTER VOLUME
- MULTIPLE LAYOUT OPTIONS FOR PLAYING COMFORT
- PRIVACY BLUR OPTION FOR FACE MASKING
- LIVE VISUAL FEEDBACK FOR MOTION AND HIT DETECTION

TECH STACK
- HTML FOR THE APP STRUCTURE
- CSS FOR LAYOUT, STYLING, AND UI DESIGN
- JAVASCRIPT FOR APP LOGIC AND INTERACTION
- MEDIAPIPE HANDS FOR HAND DETECTION
- WEB AUDIO API FOR SOUND SYNTHESIS AND PLAYBACK
- CANVAS FOR LIVE OVERLAYS AND HAND TRACKING VISUALS
- BROWSER CAMERA ACCESS FOR REAL-TIME INPUT

PROJECT PURPOSE
THIS PROJECT WAS CREATED FOR PERSONAL EXPLORATION, CREATIVE PLAY, AND DESIGN TESTING. IT SERVES AS A DEMO-READY EXPERIMENT RATHER THAN A COMMERCIAL OR FULLY PRODUCTION-LEVEL APP.
